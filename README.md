# justinevalmores.com

Welcome to my personal portfolio website. Here you can find information about my skills, experience, projects, and how to get in touch with me.

## Technologies

- React
- TypeScript
- Vite
- Bun
- AWS

## Development

First, install the dependencies by running:

```bash
bun install
```

To start the development server, run the following command:

```bash
bun dev
```

## Building for Production

To build the project for production, run the following command:

```bash
bun build
```
